Patent

Planify: The Event Hub

Patent No. SW-2025020734

Planify: The Event Hub is a web-based platform designed to simplify event management for organizations. It allows users to submit event details, maintain their organization profiles, and offer ready-made templates that clients can edit and customize easily—all from one central system.


The system includes:

  • Organization registration and login
  • Event submission with complete details
  • Editable templates for clients
  • User-friendly admin panel
  • Secure authentication and feedback handling

The platform is developed using HTML, CSS, JavaScript for the frontend and PHP with MySQL for the backend. It focuses on simplicity, responsiveness, and ease of use.


This project was developed as part of our final year capstone project for the Diploma in Computer Engineering.


Patent No.: SW-2025020734, granted on June 12, 2025, officially recognizes this project for its innovation in digital event management.
